♡ LocalFlow에서 쿠폰맵으로

기존 LocalFlow 도메인은 보류하고, 운영 중심을 쿠폰맵으로 이전하는 구조입니다. 브랜드 스토리는 남기되 사용자가 처음 만나는 화면은 지도와 이벤트 참여가 되도록 정리했습니다.

⚙ 연결 구조

기존 API_BASE, 투표 저장, 쿠폰 일정, 갤러리 로딩 구조를 유지했습니다. 쿠폰 데이터에 lat/lng가 있으면 지도 핀으로 자동 표시되고, 없으면 샘플 데이터가 fallback으로 표시됩니다.

♡ 쿠폰맵이란?

혜택을 지도 위에 올리는 로컬 프로젝트

쿠폰맵은 기존 LocalFlow의 시민 참여, 투표, 기록, 쿠폰 이벤트 구조를 지도 중심으로 재정렬한 서비스입니다.

왜 지도 중심인가?

사용자는 복잡한 설명보다 지금 어디에서 어떤 혜택이 있는지를 먼저 봅니다. 그래서 홈의 중심을 지도, 핀, 모달, 이벤트 참가로 통합했습니다.

운영 방향

업체 등록 → 지도 노출 → 이벤트 참여 → 쿠폰 발송 → 재방문 흐름으로 단순화합니다.
