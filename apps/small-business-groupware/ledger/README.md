# 일손장부 v1.0

명세: yame-specs / 3dRPbmFZqMs. 30인 미만 사업장(직원 최대 29명)의 관리자 입력 중심 웹앱.

## 시작

소개 페이지 → 장부 시작하기. 체험은 메모리에서만 실행되며 새로고침 시 초기화됩니다.
새 서버 장부는 12자 이상 암호로 만듭니다. 발급된 **장부 ID와 암호를 별도로 기록**하세요.
다른 기기에서는 같은 ID·암호로 엽니다. 암호는 복구할 수 없습니다.
서버 주소는 https://localflow.ddns.net/uvb 고정. UVB items CRUD를 사용합니다.
AES-256-GCM + PBKDF2 SHA-256(310,000회), 무작위 salt/IV. 장부·첨부·감사 이력은 암호화한 JSON만 전송합니다.
업무 화면에는 외부 스크립트를 불러오지 않습니다. 광고는 별도 소개 페이지에 한 번만 있습니다.

## 작업 순서

1. 기준정보: 직원/급여 기준, 거래처, 창고, 품목을 등록합니다. 같은 코드는 불러와 수정합니다.
2. 근태: 직원과 월 선택 → 일자 표 또는 탭 구분 붙여넣기 → 관리자 확정. 입력 안 한 날짜는 제외합니다.
3. 급여: 월 모든 날짜의 근태(휴일 포함)를 확정해야 계산할 수 있습니다. 월 기본급은 등록 금액, 주휴는 기본급 포함 여부 또는 `인정시간 × 시간단가 × 관리자가 검토한 인정 주수`. 추가근무는 관리자가 입력한 최종 금액입니다. 법정 공식을 자동 적용하지 않습니다. 하루라도 미입력·미확정이면 계산을 차단합니다.
4. 품목 가져오기: xlsx/UTF-8 CSV, 첫 표시 시트와 첫 행 헤더. 별칭 추정 → 필수 4개 열 매핑 확인 → 오류/정상 미리보기 → 정상 행만 반영. 기존 품목/파일 해시 중복 차단. 품목코드 텍스트와 0000 표시 형식을 보존하며, 원본에서 이미 잃은 0은 복원하지 않습니다. 수식은 값으로 변경해 가져옵니다. xls는 xlsx로 변환합니다.
5. 전표: 거래처/창고/날짜/증빙/결제기한/다중 품목/LOT/첨부 → 임시저장 → 확정. 과세 품목 VAT는 공급가의 10%를 원 단위 반올림하는 초기 가정, 영세/면세는 0. 확정 후 직접 수정하지 않고 취소/반품을 기록합니다.
6. 재고: 확정 매입 +, 매출 −, 반품 반대 방향. 창고·LOT별 수불과 원천 전표 ID. 기초재고/조정 사유를 남깁니다. 기본은 음수 출고 차단; 설정 허용 시 관리자 재확인과 이력 기록.
7. 원장: 조회 월·검색·정렬, 결제 기록/취소, 미수/미지급 잔액과 CSV. 월 마감 시 해당 월 수정을 잠급니다.
8. 장부 관리: 암호화 백업, 평문 JSON 내보내기, 암호화/평문 백업 복원, 감사 이력.

## 운영 한계

UVB 자체에는 인증·원자적 compare-and-set 잠금이 없습니다. 데이터 기밀성은 암호화로 보호하지만 서버의 삭제/변조/가용성까지 보장하지 않습니다. 장부 ID와 암호 공유는 업무 권한 분리가 아닙니다. **한 번에 한 기기에서 수정**하세요. 저장 전 버전 비교와 저장 후 재조회는 충돌을 검출하지만 동시 쓰기 전체를 원자적으로 막지 못합니다. 중요 변경 전후 백업하세요.
서버 연결이 없으면 실제 서버 장부를 저장할 수 없으며 성공으로 표시하지 않습니다. PWA 오프라인은 앱 화면과 체험만 지원합니다. 개인정보/장부 평문을 캐시·localStorage에 저장하지 않습니다.
첨부 PDF/PNG/JPEG 각 1MB·합계 3MB, 가져오기 10MB·10,000행. 감사 이력/첨부 포함 서버 요청이 20MB를 넘으면 UVB 제한에 걸릴 수 있습니다.
부분 반품은 새 반품 전표를 수량 조정해 입력합니다. 자동 전체 반품 초안은 원 전표 전체 수량을 복사합니다. 원전표와 연결 없는 독립 반품도 지원하는 MVP이며 과다 반품 검토는 관리자가 수행합니다.
SCM 직접 API, BOM/MRP/제조원가, 은행/카드 자동수집, 법정 신고, 직원 로그인은 범위 밖입니다.

## 구현

바닐라 HTML/CSS/JS, 외부 런타임 라이브러리 없음. 엑셀 xlsx의 ZIP/XML은 브라우저 DecompressionStream으로 읽습니다. 최신 Chromium/Firefox/Safari의 HTTPS 환경이 필요합니다.
QA는 금액/수불/취소/급여/가져오기 검증, 실제 브라우저 흐름, 서버 암호화 저장 재조회로 확인합니다.
