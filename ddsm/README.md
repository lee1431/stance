# DDSM — Daily · Scan · Delivery

로그인 없이 열리는 별도 배송 작업용 실험 버전입니다.

- 경로: `/ddsm/` (기존 `/dsd/`는 유지)
- 메인: **D** 날짜/회차, **S** 송장 바코드 스캔, **d** 배송시작
- 스캔: USB/블루투스 키보드형 바코드 리더, 번호 직접 입력, 브라우저 카메라(BarcodeDetector 또는 ZXing CDN 폴백)
- 배송 목록: 수취인/주소/연락처/메모 편집, 지도 검색 열기, 완료·완료취소·삭제
- 각 날짜·회차별 로컬 브라우저 저장, JSON 내보내기/복원
- 소스: `index.html`, `style.css`, `app.js`, `favicon.svg`.

## 중요 제약

인증을 우회하지 않습니다. 기존 DSD 서버에 연결하거나, 센터의 배송 원본 엑셀·배송 기사 계정·지도 API를 자동 조회하지 않습니다. 현재는 개인용 **localStorage 독립 실행형**으로, 기기간 자동 동기화도 없습니다. 브라우저 저장소를 삭제하거나 다른 기기를 쓰면 목록이 보이지 않으며, 백업 JSON에는 수취인 개인정보가 포함될 수 있으므로 안전하게 보관해야 합니다. 여러 탭에서 동시에 편집하면 마지막 저장이 우선될 수 있습니다.

배포는 정적 웹서버가 `/ddsm/` 하위 파일을 서비스하면 가능합니다. GitHub 저장소에 파일을 생성했다고 해서 `llsshh.com/ddsm/`의 서버 경로 설정까지 검증된 것은 아닙니다.

카메라 스캔에는 HTTPS, 카메라 권한이 필요합니다. ZXing CDN을 이용하는 브라우저는 인터넷 연결이 필요합니다. 카메라가 불가능하면 키보드형 스캐너/수동입력으로 사용할 수 있습니다. 실기 테스트는 별도 수행이 필요합니다.

추후 센터 자료와 서버 동기화를 연결하려면 공개 무인증 접근 대신 사용자/기기별 권한과 민감정보 보호 방안을 별도로 설계해야 합니다.
