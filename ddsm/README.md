# DDSM — Daily · Scan · Delivery

- 기사: https://llsshh.com/ddsm/
- 관리자: https://llsshh.com/ddsm/admin/
- API: https://mrdindoin.ddns.net/ddsm/api/

관리자는 최초 관리자 전용 연결 링크로 접속하고 센터를 선택합니다. 엑셀 업로드, 지도, 정기배송 고객 주소록을 관리합니다. 기사 연결 링크를 전달하면 기사는 최초 한 번 연결 후 별도 계정 로그인이나 센터 선택 없이 이용합니다.

기사 화면: 스캔(카메라 기본) → 지도(마커 선택 순번) → 목록(완료/취소·내비·수정/회차 변경). 원본과 주소록은 센터별로, 배송 상태는 센터·기기·배송일별로 서버에 저장합니다.

등록된 정기배송 고객의 주소와 위치는 다음 원본 업로드에서 참조합니다. 동일 이름에 여러 후보가 있으면 관리자가 확인합니다.

기존 계정 DB와 DSD는 그대로 보존하며 자동 이관하지 않습니다. 배포와 최초 센터 설정은 [API 배포 안내](api/README.md)를 따르세요. GitHub Pages와 S10 API는 별도 배포입니다.
