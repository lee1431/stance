# DDSM — Daily · Scan · Delivery

택배 배송센터에서 엑셀 원본 등록, 운송장 스캔, 배송 순번 관리 및 배송 완료 처리를 하기 위한 웹 기반 배송 관리 시스템입니다.

별도의 고가 서버 없이 안드로이드 스마트폰을 서버로 활용할 수 있도록 구성했습니다.

## 1. 시스템 구조

```text
관리자 PC / 배송 기사 스마트폰
              │
              ▼
        GitHub Pages
          프론트엔드
     (HTML / CSS / JavaScript)
              │
         HTTPS API 요청
              │
              ▼
        인터넷 / DDNS
              │
              ▼
        공유기 포트포워딩
              │
              ▼
       안드로이드 스마트폰
           Termux
              │
            Nginx
              │
     Flask / Waitress (8862)
              │
           SQLite
```

- **프론트엔드:** GitHub Pages에서 기사 화면과 관리자 화면을 제공합니다.
- **백엔드:** 스마트폰의 Termux에서 Python 기반 API 서버를 실행합니다.
- **데이터베이스:** 배송 원본, 고객 주소록, 기사 작업 내역 등은 스마트폰 서버의 SQLite에 저장합니다.

GitHub는 웹 화면을 제공하는 역할이며, 실제 배송 데이터는 별도의 스마트폰 서버에서 관리합니다. 서버용 스마트폰은 인터넷과 전원에 연결해 두고, 관리자와 기사는 각자의 기기에서 접속합니다.

## 2. 스마트폰 내부 IP 확인

서버로 사용할 스마트폰을 공유기 Wi-Fi에 연결합니다.

Termux에서 다음 명령어로 Wi-Fi IP 주소를 확인할 수 있습니다.

```bash
ifconfig wlan0
```

또는:

```bash
ip -4 addr show wlan0
```

예를 들어 `192.168.0.100`이 스마트폰의 내부 IP 주소라고 가정합니다.

Android 버전에 따라 네트워크 정보 조회가 제한될 수 있습니다. 명령어로 확인되지 않으면 스마트폰의 Wi-Fi 상세 설정 또는 공유기의 연결된 기기 목록에서 확인하세요.

공유기의 DHCP IP 예약 기능을 사용하면 스마트폰의 내부 IP 주소가 바뀌는 것을 방지할 수 있습니다.

## 3. 공유기 포트포워딩

외부에서 스마트폰 서버에 접속할 수 있도록 공유기 관리자 페이지에서 포트포워딩을 설정합니다.

아래는 설정 예시입니다.

| 항목 | 예시 |
| --- | --- |
| 프로토콜 | TCP |
| 외부 포트 | 443 |
| 내부 IP | 192.168.0.100 |
| 내부 포트 | 8443 |

```text
외부 HTTPS 접속 (443)
          │
          ▼
       공유기
          │
          ▼
192.168.0.100:8443 (Nginx)
          │
          ▼
127.0.0.1:8862 (DDSM API)
```

위 예시는 스마트폰의 Nginx가 8443 포트에서 HTTPS를 처리하도록 설정한 경우입니다. 실제 Nginx 포트에 맞춰 변경하면 됩니다.

외부 접속에는 공인 IP 또는 DDNS 주소와 HTTPS 인증서가 필요합니다. 통신사에서 공인 IP를 제공하지 않는 환경에서는 포트포워딩만으로 외부 접속이 되지 않을 수 있습니다.

Flask API의 8862 포트를 인터넷에 직접 공개하지 않고 Nginx를 통해 연결하는 것을 권장합니다.

## 4. 프론트엔드와 백엔드 연결

현재 개발·운영 환경은 다음과 같습니다.

| 구분 | 주소 |
| --- | --- |
| 기사 화면 | https://llsshh.com/ddsm/ |
| 관리자 화면 | https://llsshh.com/ddsm/admin/ |
| API | https://mrdindoin.ddns.net/ddsm/api/ |

독립적으로 운영하는 경우 프론트엔드의 API 주소, 백엔드의 허용 오리진(`DDSM_ORIGIN`), NAVER Maps Client ID를 자신의 환경에 맞게 변경합니다.

API 서버가 실행 중인지 Termux에서 확인하려면:

```bash
curl http://127.0.0.1:8862/ddsm/api/health
```

외부 접속은 스마트폰의 Wi-Fi를 끈 다른 기기 등에서 자신의 HTTPS API 주소 뒤에 `/ddsm/api/health`를 붙여 확인합니다.
