배송이 처음이거나, 낯선 지역을 맡으셨나요?
DSD는 운송장 스캔으로 배송지를 확인하고, 지도에서 배송 순서를 정할 수 있도록 돕는 배송기사용 보조 서비스입니다.

복잡한 배송관리 프로그램이 아닙니다. 기사님이 자신의 물량을 싣고 나갈 때, 필요한 기능에 집중했습니다.

DSD 사용 흐름

배송기사에게 필요한 일만 남깁니다

운송장을 스캔한 물량이 내 배송목록이 됩니다.

STEP 01

원본 데이터 준비

센터에서 당일 전체 물량을 한 번 공급하는 구조를 지향합니다. 기사가 엑셀 파일을 따로 관리하지 않도록 합니다.

STEP 02

물건을 싣고 스캔

기사 본인 계정으로 로그인한 뒤, 실제 차량에 싣는 물품의 운송장을 스캔합니다.

STEP 03

배송지와 순서 확인

스캔한 물량의 배송지를 지도와 목록에서 보고, 추천 순서를 검토하거나 직접 조정합니다.

STEP 04

출발하고 완료 체크

정해진 순서대로 배송하면서 완료한 곳을 표시하고, 남은 배송지를 확인합니다.

서비스 개발 안내 · 센터의 당일 전체 원본을 여러 기사 계정이 공동 조회하는 기능은 현재 확장 중입니다. 실제 바코드 조회는 사전에 준비된 원본 데이터와 배송일이 일치해야 하며, 지도·경로 기능에는 네이버 지도 API 연결 등이 필요합니다.

DSD의 역할

택배사 본 프로그램을 대신하지 않습니다

센터의 관리 체계를 바꾸려는 서비스가 아니라, 현장에서 일하는 배송기사를 위한 독립적인 보조 도구입니다.

센터는 데이터 공급

기사별로 엑셀을 나눌 필요 없이

센터에서는 당일 배송 원본을 제공하고, 배송기사들은 필요한 운송장 정보를 조회하는 것이 목표입니다. 기존 업무 방식을 강제로 바꾸지 않습니다.

기사는 자기 배송에 집중

스캔한 물건만 내 목록으로

배송기사별 물량과 회차, 배송 순서, 완료 기록은 각자 관리합니다. 기사 개인의 편리함이 DSD의 중심입니다.

자주 묻는 질문

이것만은 알고 시작하세요

배송을 오래 한 기사도 사용할 수 있나요?

물론입니다. 다만 DSD는 특히 신규 기사, 대체 기사, 낯선 권역을 맡은 기사에게 초점을 맞춥니다. 기존 방식이 더 편하다면 꼭 사용할 필요는 없습니다.

배송기사가 엑셀 파일을 직접 올려야 하나요?

지향하는 방식은 아닙니다. 센터가 당일 전체 물량을 제공하고 기사는 스캔만 하는 구조를 구축 중입니다. 현재 사용 환경에 따라 원본 업로드 방식이 다를 수 있습니다.

DSD가 택배사 공식 프로그램인가요?

아닙니다. DSD는 택배사 본 시스템을 대체하지 않는 독립적인 서드파티 배송 보조 서비스입니다. 택배사의 공식 배송 처리 절차는 기존 시스템을 따릅니다.

스캔만 하면 자동으로 배송이 완료되나요?

아닙니다. 스캔은 배송목록에 물량을 등록하기 위한 단계입니다. 배송 완료는 실제 배송 후 기사가 확인해야 합니다.

익숙해질 때까지, DSD와 함께.

배송 순서를 고민하는 시간을 줄이고, 실제 배송에 집중하세요.
