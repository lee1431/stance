배송 코스 편성

날짜별 1회차부터 N회차까지 별도 배송지를 관리합니다. 회차를 선택하면 저장된 순서를 불러오며, UVB에는 암호화해 저장합니다.

센터별 독립 코스

UVB는 공개 읽기 서버입니다. 고객 정보는 암호화해 저장하고 비밀번호는 보관하지 않습니다.

코스를 준비하고 있습니다.

공개 OSRM 도로 서버로 정차 좌표를 전송합니다. 출발점 포함 최대 16곳만 지원하며 운영용이 아닙니다.

첫 배송지 기준

네이버 지도 연결

NAVER Maps Client ID를 한 번 입력하면 지도가 나타납니다.

등록된 배송지

지도에서 차량 정차점을 클릭하세요. 주정차 가능 여부는 별도 확인이 필요합니다.

배송지 현장 정보

정차점 미설정

선택한 정차점은 경로 계산을 위한 참고 좌표입니다. 실제 도로 접근·주차 적법성은 검증되지 않습니다.

배송 주소 등록

업체명은 지도 마커 위에 표시됩니다. 주소를 입력하면 좌표를 찾아 등록합니다.

네이버 지도 설정

네이버 클라우드의 Maps JavaScript API용 Client ID를 입력하세요. Client Secret은 필요하지 않습니다.

네이버 클라우드에서 접속 도메인을 Web 서비스 URL로 등록해야 합니다.
