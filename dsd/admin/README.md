# DSD 센터 관리자 페이지

URL: https://llsshh.com/dsd/admin/

## 화면

1. 관리자 로그인: 고정 ID `admin`, 관리자가 최초 한 번 정한 비밀번호
2. 엑셀 업로드: 날짜를 선택하고 원본 파일 업로드
3. 전체 지도: 좌표가 있는 당일 배송 물품을 배송지별 마커로 표시. 동일 배송지는 마커의 숫자로 물품 건수 표시
4. 배송 목록: 엑셀의 모든 원본 열 표시 및 검색. 주소 미확인 건도 목록에 표시

일반 기사 계정, 휴대폰 번호, 사용자 비밀번호, 이중 관리자 인증은 **사용하지 않습니다**.

## API 연결

브라우저에서 `https://mrdindoin.ddns.net/dsd-center-api/`로 요청합니다.
`POST admin/login`은 고정 관리자 ID와 비밀번호를 검증하고 12시간 토큰을 발급합니다.
이후 요청은 `Authorization: Bearer <token>` 헤더로 인증합니다.
토큰은 페이지의 메모리에만 보관하므로 새로고침 시 다시 로그인해야 합니다.
관리자 ID·해시 설정과 S10 배포 절차는 [DSD 관리자 API 안내](../api/README.md)를 참고하세요.

엑셀 데이터 저장, 원본 컬럼 보존, 정기 배송지 주소·좌표 재사용은 S10의 관리자 API가 담당합니다. 주소가 없거나 네이버 지도에서 지오코딩이 실패한 배송은 지도에 표시할 수 없으며, 목록의 '위치 미확인'으로 표시됩니다. 조회 버튼으로 날짜별 자료를 확인할 수 있습니다.

**GitHub 정적 페이지 반영과 S10 서버 파일 적용은 별개의 작업입니다.** S10에 새 `admin.py`를 배포하고 Waitress를 재시작해야 새 로그인 방식이 동작합니다.
